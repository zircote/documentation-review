# Diátaxis Quality Criteria & Scoring Rubrics

Detailed evaluation criteria for each documentation quadrant.

## Scoring Scale

| Score | Label | Meaning |
|-------|-------|---------|
| 5 | Exemplary | Best-practice example of this quadrant |
| 4 | Good | Minor improvements possible |
| 3 | Adequate | Meets basic quadrant requirements |
| 2 | Below standard | Significant quadrant violations |
| 1 | Poor | Wrong quadrant or fundamentally misaligned |

---

## Tutorial Quality Criteria

### Mode Purity (weight: 30%)
| Score | Criteria |
|-------|----------|
| 5 | Pure learning experience — zero reference dumps, zero extended explanation |
| 4 | Minimal deviation — one or two brief explanatory asides (1-2 sentences) |
| 3 | Occasional drift — some sections explain "why" at length |
| 2 | Frequent mixing — interleaves reference tables or detailed explanations |
| 1 | Not a tutorial — primarily reference or explanation content |

### Learning Path (weight: 25%)
| Score | Criteria |
|-------|----------|
| 5 | Clear destination shown, every step produces visible result, logical progression |
| 4 | Good progression with minor gaps in visible results |
| 3 | Steps are logical but some produce no visible feedback |
| 2 | Unclear progression, reader unsure what they're building toward |
| 1 | No coherent learning path — random collection of steps |

### Reliability (weight: 25%)
| Score | Criteria |
|-------|----------|
| 5 | Every step tested, expected outputs documented, edge cases handled |
| 4 | Most steps tested, outputs mostly documented |
| 3 | Steps appear correct but expected outputs are sparse |
| 2 | Some steps may fail for common configurations |
| 1 | Steps are untested or known to fail |

### Tone & Language (weight: 10%)
| Score | Criteria |
|-------|----------|
| 5 | Inclusive first-person plural, direct instructions, encouraging |
| 4 | Mostly appropriate tone with minor inconsistencies |
| 3 | Functional but impersonal or overly formal |
| 2 | Condescending, overly technical, or confusing |
| 1 | Inappropriate tone for learning context |

### Cross-references (weight: 10%)
| Score | Criteria |
|-------|----------|
| 5 | Links to related how-to guides, explanation, and reference at appropriate points |
| 4 | Links to most related documents |
| 3 | Links to some related content |
| 2 | Few or no cross-references |
| 1 | No cross-references, island document |

## How-to Guide Quality Criteria

### Mode Purity (weight: 30%)
| Score | Criteria |
|-------|----------|
| 5 | Pure task execution — no teaching, no extended explanation, no reference dumps |
| 4 | Minimal deviation — brief contextual notes that don't distract |
| 3 | Occasional drift — some sections teach basics or explain at length |
| 2 | Frequent mixing — interleaves tutorial-style learning or reference tables |
| 1 | Not a how-to — primarily tutorial or explanation content |

### Goal Clarity (weight: 25%)
| Score | Criteria |
|-------|----------|
| 5 | Title states exact goal, first paragraph confirms what user will accomplish |
| 4 | Goal clear from title, brief introduction |
| 3 | Goal becomes clear after reading introduction |
| 2 | Goal is ambiguous — could apply to multiple outcomes |
| 1 | No clear goal stated |

### Practical Focus (weight: 25%)
| Score | Criteria |
|-------|----------|
| 5 | Every section advances toward the goal, real-world complexity addressed |
| 4 | Mostly focused, minor tangents |
| 3 | Some unnecessary content, but goal is achievable |
| 2 | Significant tangents, user may lose track of goal |
| 1 | Content doesn't clearly serve the stated goal |

### Sequencing (weight: 10%)
| Score | Criteria |
|-------|----------|
| 5 | Steps follow natural workflow, minimal context-switching |
| 4 | Logical sequence with minor ordering improvements possible |
| 3 | Steps are correct but ordering could be improved |
| 2 | Confusing order, unnecessary back-and-forth |
| 1 | No coherent sequence |

### Cross-references (weight: 10%)
| Score | Criteria |
|-------|----------|
| 5 | Links to reference for detailed options, explanation for context |
| 4 | Links to most related documents |
| 3 | Some cross-references present |
| 2 | Few or no cross-references |
| 1 | No cross-references |

## Reference Quality Criteria

### Mode Purity (weight: 30%)
| Score | Criteria |
|-------|----------|
| 5 | Pure description — no instructions, no explanation, no opinion |
| 4 | Minimal deviation — brief usage hints that don't constitute instructions |
| 3 | Some how-to content mixed in (e.g., "to use this, first...") |
| 2 | Frequently includes instructions or explanations |
| 1 | Not reference — primarily how-to or explanation content |

### Accuracy & Completeness (weight: 30%)
| Score | Criteria |
|-------|----------|
| 5 | Every element documented, all parameters/options/types accurate and current |
| 4 | Nearly complete, minor gaps in edge cases |
| 3 | Core elements documented, some options or types missing |
| 2 | Significant gaps — common elements undocumented |
| 1 | Incomplete or inaccurate — cannot be relied upon |

### Structure (weight: 20%)
| Score | Criteria |
|-------|----------|
| 5 | Mirrors product structure perfectly, consistent patterns throughout |
| 4 | Good structural alignment, minor inconsistencies |
| 3 | Reasonable structure but doesn't fully mirror product |
| 2 | Inconsistent structure, hard to navigate |
| 1 | No coherent structure |

### Tone (weight: 10%)
| Score | Criteria |
|-------|----------|
| 5 | Austere, factual, neutral — no marketing or opinion |
| 4 | Mostly neutral with minor editorial comments |
| 3 | Occasionally conversational or opinionated |
| 2 | Frequently informal or includes marketing language |
| 1 | Inappropriate tone for reference material |

### Cross-references (weight: 10%)
| Score | Criteria |
|-------|----------|
| 5 | Links to how-to guides showing practical usage |
| 4 | Links to most related practical content |
| 3 | Some cross-references to guides |
| 2 | Few cross-references |
| 1 | No cross-references |

## Explanation Quality Criteria

### Mode Purity (weight: 30%)
| Score | Criteria |
|-------|----------|
| 5 | Pure understanding — no step-by-step, no API descriptions, no instructions |
| 4 | Minimal deviation — brief illustrative examples that don't become procedures |
| 3 | Some procedural or reference content mixed in |
| 2 | Frequently includes how-to steps or reference tables |
| 1 | Not explanation — primarily another quadrant |

### Depth & Context (weight: 25%)
| Score | Criteria |
|-------|----------|
| 5 | Rich context: history, design decisions, trade-offs, alternatives considered |
| 4 | Good context with some depth |
| 3 | Adequate context but surface-level |
| 2 | Shallow — states facts without explaining significance |
| 1 | No meaningful context provided |

### Connections (weight: 20%)
| Score | Criteria |
|-------|----------|
| 5 | Weaves connections across topics, illuminates relationships |
| 4 | Makes some useful connections |
| 3 | Limited connections — mostly self-contained |
| 2 | Isolated treatment — no connections to broader context |
| 1 | Fragmented — disconnected statements |

### Scope Discipline (weight: 15%)
| Score | Criteria |
|-------|----------|
| 5 | Tightly bounded topic, clear scope, resists absorbing other modes |
| 4 | Well-bounded with minor scope creep |
| 3 | Topic defined but boundaries blurry |
| 2 | Scope unclear — drifts significantly |
| 1 | Unbounded — tries to cover everything |

### Cross-references (weight: 10%)
| Score | Criteria |
|-------|----------|
| 5 | Links to tutorials for hands-on learning, reference for details |
| 4 | Links to most related documents |
| 3 | Some cross-references |
| 2 | Few cross-references |
| 1 | No cross-references |
